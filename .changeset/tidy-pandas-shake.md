Add `@open-cells/mcp-server`, a Model Context Protocol server for Open Cells applications.

It exposes seven tools over stdio: route listing and validation, a map of the pub/sub state
channels, page and application scaffolding, and the framework API reference plus a documentation
search. Project analysis is done with the TypeScript AST, and the API reference and concept guides
are also available as MCP resources.
